# Product Recommendation System

## About the Project
The Product Recommendation System is a Python-based project that recommends products to customers by analyzing their previous purchases.

It uses the **Jaccard Similarity Algorithm** to calculate the similarity between customers, finds the most similar customer, and recommends products that the selected customer has not purchased.

## Features
- Customer purchase data stored using Python dictionaries.
- Jaccard similarity calculation using sets.
- Finds the most similar customer.
- Recommends previously unpurchased products.
- Suggests the most popular product when no similar customer is found.
- Handles invalid and empty customer names.

## Technologies Used
- Python 3
- Dictionaries
- Lists and Sets
- Functions
- Jaccard Similarity Algorithm

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python product_recommendation_system.py
```

4. Enter a customer name to get product recommendations.
